## 🐛 Bugs Corrigidos

### Controle Financeiro — Pedidos Duplicados
- **Causa:** `renderFinancial` buscava pedidos duas vezes.
- **Correção:** Removida chamada redundante ao `OrderManager`.
- **Arquivo:** `scripts/pages/admin.js`

### "Minhas Compras" não aparecia
- **Causa:** Filtro Supabase quebrava quando email era string vazia.
- **Correção:** Filtro dinâmico — só adiciona `client_email` se não for vazio.
- **Arquivo:** `scripts/pages/profile.js → loadMyOrders`

### `<script>` dentro de innerHTML não executava
- **Causa:** Scripts injetados via `innerHTML` não são executados pelo browser.
- **Correção:** `ui-auth.js` agora calcula `_profileHref` antes de montar o HTML.
- **Arquivo:** `scripts/components/ui-auth.js`

### Login via Magic Link deslogava ao navegar
- **Causa:** Evento `SIGNED_OUT` do Supabase disparava durante navegação de página.
- **Correção:** `auth.js` ignora `SIGNED_OUT` nos primeiros 15s após login.
- **Arquivo:** `scripts/services/auth.js`

### Header `index.html` sempre mostrava "Entrar"
- **Causa:** Linha `const cached = null; // FORCE GUEST VIEW FOR DEMO` travada.
- **Correção:** Restaurado para ler `emergency_user` e `mv_user_cache` do localStorage.
- **Arquivo:** `index.html` (IIFE de renderização instantânea)

### Botão "Sair da Conta" travava tudo
- **Causa:** `authService.logout()` era `async` e `supabase.auth.signOut()` pendurava sem sessão real.
- **Correção 1:** Logout refatorado para síncrono com `signOut` fire-and-forget.
- **Correção 2:** Scripts inexistentes (`orders.js`, `constants.js`) removidos do `profile.html` — causavam bloqueio de carregamento de JS.
- **Botão reescrito** com inline JS direto sem depender de `authService`.
- **Arquivos:** `auth.js`, `profile.html`

### Links "Catálogo" e "Início" em `login.html` davam 404
- **Causa:** `href="index.html"` na pasta `/pages/` aponta para `/pages/index.html` (inexistente).
- **Correção:** Trocado para `href="../index.html"`.
- **Arquivo:** `pages/login.html`
