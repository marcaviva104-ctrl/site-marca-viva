# 🚀 Como Configurar Live Server no VS Code

## 📋 **PASSO A PASSO COMPLETO**

---

## 1️⃣ **INSTALAR LIVE SERVER**

### **Método Visual (Recomendado):**

1. **Abra o VS Code**
2. **Clique** no ícone de extensões (quadradinhos no lado esquerdo)
   - Ou pressione `Ctrl + Shift + X`
3. **Digite** na caixa de busca: `Live Server`
4. **Procure** por "Live Server" (autor: Ritwick Dey)
5. **Clique** em "Install" (Instalar)
6. ✅ Aguarde a instalação concluir!

### **Método Rápido:**

1. Pressione `Ctrl + P`
2. Digite: `ext install ritwickdey.liveserver`
3. Pressione Enter

---

## 2️⃣ **ABRIR O PROJETO**

1. **No VS Code**, vá em: `File` → `Open Folder`
2. **Navegue** até: `C:\Users\Leivin Jesus\OneDrive\Desktop\SiteMarcaViva`
3. **Clique** em "Selecionar pasta"

---

## 3️⃣ **INICIAR O LIVE SERVER**

### **Método 1: Botão Direito**
1. **Localize** o arquivo `index.html` no explorador de arquivos (lado esquerdo)
2. **Clique com botão direito** no `index.html`
3. **Selecione**: "Open with Live Server"
4. ✅ Uma janela do navegador abrirá automaticamente!

### **Método 2: Botão na Barra**
1. **Abra** o arquivo `index.html`
2. **Procure** no canto inferior direito da tela
3. **Clique** no botão "Go Live" (ou "Ativar")
4. ✅ Site abrirá em `http://127.0.0.1:5500`

---

## 4️⃣ **VERIFICAR SE ESTÁ FUNCIONANDO**

Você verá no navegador:
```
http://127.0.0.1:5500/index.html
```

✅ **Sinais que está certo:**
- URL começa com `http://` (não `file://`)
- Produtos carregam no catálogo
- Pode fazer login

---

## 5️⃣ **CONFIGURAÇÕES OPCIONAIS**

### **Mudar a Porta:**
1. No VS Code: `File` → `Preferences` → `Settings`
2. Busque: `Live Server Port`
3. Mude de `5500` para outra (ex: `8000`)

### **Auto-Refresh:**
O Live Server recarrega automaticamente quando você salvar arquivos! 🔥

## ⚠️ **PROBLEMAS COMUNS:**

### **Live Server não aparece:**
- Reinicie o VS Code
- Verifique se instalou corretamente

### **Página não carrega:**
- Verifique se o Live Server está ativo (botão "Go Live")
- Tente outra porta

### **Mercado Pago não aparece:**
- Verifique se está em `http://` (não `file://`)
- Abra o console (F12) e veja erros
