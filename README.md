# SiteMarcaViva

Welcome to the **SiteMarcaViva** repository. This project is the digital storefront for Marca Viva.

## 🚀 Quick Start (The "Golden Path")

1.  **Clone & Open**: Open this folder in VS Code.
2.  **Run Locally**: Open `index.html` in your browser (preferably using Live Server).
3.  **Explore**:
    *   `src`: The code (HTML/CSS/JS).
    *   `docs`: The brain (Decisions, Specs, Guides).
    *   **[🗺️ MAPA DO SISTEMA EM PORTUGUÊS](docs/MAPA_DO_SISTEMA.md)** (Entenda o que cada arquivo faz).

## 📂 Project Structure

We follow a "Docs as Code" philosophy.

*   `docs/architecture/`: **ADRs** (Why we built it this way).
*   `docs/product/`: **Specs** (What we are building).
*   `docs/team/`: **Onboarding** (How we work).
*   `docs/archive/`: **Graveyard** (Old backups and scraps).

## 🛠 Contributing

1.  **Found a bug?** Copy `docs/templates/000-bug-report-template.md` and fill it out.
2.  **New Feature?** Start with `docs/templates/000-spec-template.md`.
3.  **Major Decision?** Write an `ADR` in `docs/architecture/decisions`.
